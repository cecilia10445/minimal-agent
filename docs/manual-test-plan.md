# 手动测试计划 — minimal_agent

本文档记录 minimal_agent 项目所有手动执行的测试场景。

状态标签：
- ✅ **通过** — 测试成功完成
- ❌ **失败** — 测试发现缺陷（已修复，需要重新测试）
- 🔄 **需要重新测试** — 修复后需要重新验证的场景
- ⏳ **未执行** — 已计划但尚未运行
- ❓ **讨论中** — 开放的设计问题
